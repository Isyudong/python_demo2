# 像素坐标转换系统使用说明

## 功能概述
本系统已经集成了像素坐标到实际毫米坐标的转换功能，可以将检测到的目标位置从像素坐标转换为实际的毫米坐标后发送给Arduino。

## 主要特性

### 1. 坐标转换
- 当前转换比例: **4.40 pixels/mm**
- 系统会自动将检测到的目标像素坐标转换为实际毫米坐标
- 转换后的坐标会发送给Arduino进行进一步处理

### 2. 配置管理
- 通过 `config.py` 文件管理所有参数
- 支持动态修改转换比例和其他参数
- 如果没有配置文件，程序会使用默认参数

### 3. 参数说明

#### 转换比例 (PIXELS_PER_MM)
- 默认值: 4.40 pixels/mm
- 修改方法: 在 `config.py` 中修改 `PIXELS_PER_MM` 的值
- 示例: 如果要改为 5.0 pixels/mm，设置 `PIXELS_PER_MM = 5.0`

#### 圆形检测参数 (CIRCLE_DETECTION_PARAMS)
- dp: 检测精度参数
- minDist: 圆心之间的最小距离
- param1, param2: 边缘检测参数
- minRadius, maxRadius: 检测圆的半径范围

#### 黄色检测参数 (YELLOW_HSV_RANGE)
- h_min, h_max: 色调范围
- s_min: 饱和度最小值
- v_min: 亮度最小值

## 使用方法

### 1. 修改转换比例
编辑 `config.py` 文件：
```python
PIXELS_PER_MM = 4.40  # 修改为你需要的比例
```

### 2. 运行程序
```bash
python justTest.py
```

### 3. 程序输出
- 程序启动时会显示当前所有配置参数
- 检测到目标时会同时显示像素坐标和实际毫米坐标
- 发送给Arduino的是实际毫米坐标

### 4. 数据格式
发送给Arduino的数据格式：
```
X12.34,Y56.78/n
```
其中 X12.34, Y56.78 是实际的毫米坐标

## 测试和校准

### 1. 验证转换比例
- 在已知实际距离的物体上测试
- 比较像素距离和实际距离的比值
- 调整 `PIXELS_PER_MM` 参数

### 2. 精度测试
- 使用标准测量工具验证转换精度
- 在不同位置和距离下测试
- 确保转换误差在可接受范围内

## 注意事项

1. **转换比例的准确性**
   - 转换比例取决于相机的分辨率和视野范围
   - 需要根据实际标定结果调整

2. **座标系统**
   - 像素坐标原点在图像左上角
   - 实际坐标系统需要根据应用场景定义

3. **参数调整**
   - 修改配置文件后需要重启程序
   - 建议先备份原始配置文件

4. **错误处理**
   - 程序会自动处理配置文件缺失的情况
   - 使用默认配置确保程序正常运行

## 故障排除

1. **转换结果不准确**
   - 检查 PIXELS_PER_MM 参数是否正确
   - 重新进行相机标定

2. **检测精度问题**
   - 调整圆形检测参数
   - 优化图像预处理

3. **通信问题**
   - 检查Arduino串口配置
   - 确认数据格式正确性
